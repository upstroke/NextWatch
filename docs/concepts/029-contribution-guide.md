# Contribution guide

## Status

Completed.

## Purpose

This concept documents the contribution workflow for NextWatch.

It defines the order of work from inventory to implementation, testing, documentation and approval.

## Workflow

1. Complete the inventory.
2. Make architecture decisions based on the inventory.
3. Implement the change.
4. Add behavior-focused tests.
5. Document decisions, discarded approaches and open questions.
6. Obtain explicit user approval for GitHub write actions.

## Rules

- Verify before claiming.
- Preserve the overall concept.
- Avoid premature abstraction.
- Use the existing foundation first.
- Separate entity lookup from Discover.
- Keep tests behavior-focused.
- Document decisions.

## Approval rule

Every GitHub write action requires explicit user approval.

## Out of scope

- Automatic activation of additional capabilities without separate verification.
- Premature architectural consolidation.
- Claims about unverified implementation details.
