# Definition of done

## Status

Completed.

## Purpose

This concept documents the definition of done for NextWatch tasks.

It defines the minimum requirements before a task is considered complete.

## Definition of done

A task is done when:

- The inventory is complete.
- The implementation is based on the inventory.
- Tests verify behavior, not artificially cover branches.
- Documentation records decisions, discarded approaches and open questions.
- The user has approved the implementation.

## Coverage rule

The project does not target 100% coverage.

A minimum of 80% statement coverage is sufficient.

## Documentation rule

Document decisions, discarded approaches and open questions.

This prevents repeated mistakes and preserves context for future work.

## Approval rule

Every GitHub write action requires explicit user approval.

## Out of scope

- Automatic activation of additional capabilities without separate verification.
- Premature architectural consolidation.
- Claims about unverified implementation details.
