# Accessibility

## Status

Completed.

## Purpose

This concept documents the accessibility foundations for NextWatch.

It defines rules for semantic HTML, keyboard navigation, visible focus states, meaningful labels and deliberate accessibility testing.

## Semantic HTML

Use semantic HTML.

Do not replace semantic elements with generic elements without a documented reason.

## Keyboard navigation

Interactive elements must be operable with a keyboard.

Do not rely on mouse-only interactions.

## Focus states

Focus states must be visible.

Do not remove focus indicators without an accessible replacement.

## Labels

Interactive elements must have meaningful labels.

Do not rely on placeholder text as the only label.

## Testing

Accessibility testing is deliberate.

Do not claim accessibility without verification.

## Out of scope

- Automatic activation of additional accessibility capabilities without separate verification.
- Claims about unverified implementation details.
