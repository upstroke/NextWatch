# Future work

## Status

Completed.

## Purpose

This concept documents the intentionally deferred work for NextWatch.

It records work that is not part of the current Search Flow Restart.

## Deferred work

The following work is intentionally deferred:

- Detail page UI.
- Routing and navigation.
- Filter pills.
- URL state.
- Infinite scroll.
- Backdrops.
- Mixed Movie/TV result lists.
- LLM or Ollama integration.

## Rule

Do not activate deferred work without separate verification.

## Out of scope

- Automatic activation of additional capabilities without separate verification.
- Premature architectural consolidation.
- Claims about unverified implementation details.
